# Complete App Store Submission - Final Steps

## ✅ Current Status
- Build 1.0.0 (14) is successfully uploaded to TestFlight
- Build is ready to be selected in App Store Connect

## 📋 Required Steps to Submit for Review

### Step 1: Navigate to Prepare for Submission Page
**Direct Link**: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight

---

### Step 2: Select Build 1.0.0 (14)
1. On the "Prepare for Submission" page, scroll to the **"Build"** section
2. Click **"Select a build before you submit your app"** or **"Add Build"** button
3. In the build selection dialog, look for **"1.0.0 (14)"**
4. Select build **1.0.0 (14)**
5. Click **"Done"** or **"Save"**

**Note**: If build 1.0.0 (14) doesn't appear yet, wait 10-15 minutes for Apple to process it.

---

### Step 3: Select Primary Category
**Location**: App Information section

1. Navigate to: https://appstoreconnect.apple.com/apps/6756714869/distribution/info
2. Scroll to **"App Store Information"** section
3. Find **"Primary Category"** dropdown
4. Select: **Travel** (recommended for apartment booking app)
   - **Alternative**: **Lifestyle** (also appropriate)
5. Click **"Save"** at the top right

---

### Step 4: Complete App Privacy Usage Purposes (Admin Required)
**Location**: App Privacy section

1. Navigate to: https://appstoreconnect.apple.com/apps/6756714869/distribution/privacy
2. You should see 5 data type cards already added:
   - Name
   - Email Address
   - Phone Number
   - Payment Info
   - Photos or Video

3. **For EACH of the 5 data types**, click on the data type card:

   **Configuration for each data type:**
   - **What is the data used for?**
     - Select: **App Functionality** (required)
   - **Is this data linked to the user's identity?**
     - Select: **Yes**
   - **Is this data used to track the user?**
     - Select: **No** (since we removed tracking permission)
   - Click **"Save"** or **"Continue"**

4. After configuring all 5 data types, click **"Publish"** or **"Submit"** button at the top

**Note**: Requires Admin role. If you see a message that an Admin must complete this, make sure you're logged in as an Admin user.

---

### Step 5: Select Price Tier
**Location**: Pricing and Availability section

1. Navigate to: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight
2. Scroll to **"Pricing and Availability"** section
3. Click **"Edit"** or the price field
4. Select price tier: **Free** (recommended for marketplace app)
5. Select countries/regions: **All Countries** (default)
6. Click **"Save"**

---

### Step 6: Complete Age Rating Questionnaire
**Location**: Ratings and Review section

1. Navigate to: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight
2. Scroll to **"Ratings and Review"** section
3. Click **"Edit"** or **"Manage Rating"**
4. Complete the Apple Content Description questionnaire:

   For each category, select the frequency:
   - **Cartoon or Fantasy Violence**: **None**
   - **Realistic Violence**: **None**
   - **Profanity or Crude Humor**: **None**
   - **Sexual Content or Nudity**: **None**
   - **Alcohol, Tobacco, or Drug Use**: **None**
   - **Mature/Suggestive Themes**: **None**
   - **Gambling and Contests**: **None** (unless app has contests)
   - **Horror/Fear Themes**: **None**
   - **Medical/Treatment Information**: **None**
   - **Unrestricted Web Access**: **None** or **Infrequent** (if using WebView)

5. Review the calculated age rating (should be **4+**)
6. Click **"Save"** or **"Done"**

---

### Step 7: Verify Required Fields
Go back to: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight

Check that the following are completed:

**Required Fields:**
- ✅ **Description**: Should be filled in (check if empty)
- ✅ **Subtitle**: Should be filled in (check if empty)
- ✅ **Privacy Policy URL**: Should be added (check if required)

If any of these are missing:
- **Description**: Add app description (2-4 sentences about the app)
- **Subtitle**: Add subtitle (30 characters max)
- **Privacy Policy URL**: Add your privacy policy URL (required if collecting user data)

---

### Step 8: Final Verification
Before submitting, verify:

1. Go to: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight
2. Check the top of the page for any error messages or warnings
3. Scroll through all sections and ensure:
   - ✅ Build selected (1.0.0 (14))
   - ✅ Primary category selected
   - ✅ App Privacy published
   - ✅ Price tier selected
   - ✅ Age rating completed
   - ✅ Description filled
   - ✅ Subtitle filled
   - ✅ Privacy Policy URL added (if required)
   - ✅ Screenshots uploaded (should already be done)

---

### Step 9: Submit for Review
1. Scroll to the bottom of the "Prepare for Submission" page
2. Look for the **"Add for Review"** button
3. If the button is **enabled** (blue, clickable):
   - Click **"Add for Review"**
   - Review any final confirmation dialog
   - Confirm submission
4. If the button is **disabled** (gray):
   - Check for any remaining error messages at the top of the page
   - Complete any missing required items
   - Refresh the page and try again

---

## ✅ After Submission

Once you click "Add for Review":
1. **Status changes** to "Waiting for Review"
2. **Email notification** will be sent confirming submission
3. **Review timeline**: Apple typically reviews within 24-48 hours (can be faster or slower)
4. **Status updates**: You'll receive email notifications about review progress
5. **If approved**: App will be released according to your settings (automatic or manual)

---

## 🔍 Troubleshooting

### "Add for Review" Button is Disabled
**Possible causes:**
1. Missing required field (check error messages at top of page)
2. Build not selected
3. App Privacy not published
4. Primary category not selected
5. Price tier not selected
6. Age rating not completed

**Solution**: Check each section and complete missing items.

### Build 1.0.0 (14) Not Showing in Build List
**Possible causes:**
1. Build still processing (wait 10-15 more minutes)
2. Wrong app selected in App Store Connect

**Solution**: 
- Wait a few more minutes
- Verify you're in the correct app: https://appstoreconnect.apple.com/apps/6756714869

### App Privacy Requires Admin
**Solution**: Make sure you're logged in with an Admin account. If you don't have Admin access, contact your Apple Developer account administrator.
