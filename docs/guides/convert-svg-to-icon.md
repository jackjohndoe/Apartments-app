# Converting Suhw201.svg to Icon

## Quick Method: Online Converter

1. **Go to:** https://cloudconvert.com/svg-to-png
2. **Upload:** `assets/Suhw201.svg`
3. **Settings:**
   - Width: 1024
   - Height: 1024
   - Background: White (#FFFFFF) or Gold (#FFD700)
4. **Convert and Download**
5. **Save as:** `assets/icon.png` (replace existing)

## Alternative: Using Inkscape (Free Desktop App)

1. Download Inkscape: https://inkscape.org
2. Open `assets/Suhw201.svg`
3. File → Export PNG Image
4. Set size: 1024x1024px
5. Export as `icon.png`
6. Replace `assets/icon.png`

## Using Node.js (If you have it installed)

```bash
npm install -g svg2png-cli
svg2png assets/Suhw201.svg --output assets/icon.png --width 1024 --height 1024
```
