## 📋 Step-by-Step Checklist

### Step 1: Select Build 1.0.0 (14)
**Link**: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight

- [ ] Navigate to Prepare for Submission page
- [ ] Find "Build" section
- [ ] Click "Select a build" or "Add Build"
- [ ] Select build **1.0.0 (14)** from the list
- [ ] Click "Done" or "Save"

---

### Step 2: Select Primary Category
**Link**: https://appstoreconnect.apple.com/apps/6756714869/distribution/info

- [ ] Navigate to App Information page
- [ ] Find "Primary Category" dropdown (under App Store Information)
- [ ] Select: **Travel** (recommended) or **Lifestyle**
- [ ] Click "Save"

---

### Step 3: Complete App Privacy Usage Purposes ⚠️ ADMIN REQUIRED
**Link**: https://appstoreconnect.apple.com/apps/6756714869/distribution/privacy

- [ ] Navigate to App Privacy page
- [ ] See 5 data type cards (Name, Email, Phone, Payment, Photos)
- [ ] Click on **Name** data type card
  - [ ] Select "App Functionality" for usage purpose
  - [ ] Select "Yes" for linked to user identity
  - [ ] Select **"No"** for used for tracking
  - [ ] Click "Save"
- [ ] Click on **Email Address** data type card
  - [ ] Select "App Functionality" for usage purpose
  - [ ] Select "Yes" for linked to user identity
  - [ ] Select **"No"** for used for tracking
  - [ ] Click "Save"
- [ ] Click on **Phone Number** data type card
  - [ ] Select "App Functionality" for usage purpose
  - [ ] Select "Yes" for linked to user identity
  - [ ] Select **"No"** for used for tracking
  - [ ] Click "Save"
- [ ] Click on **Payment Info** data type card
  - [ ] Select "App Functionality" for usage purpose
  - [ ] Select "Yes" for linked to user identity
  - [ ] Select **"No"** for used for tracking
  - [ ] Click "Save"
- [ ] Click on **Photos or Video** data type card
  - [ ] Select "App Functionality" for usage purpose
  - [ ] Select "Yes" for linked to user identity
  - [ ] Select **"No"** for used for tracking
  - [ ] Click "Save"
- [ ] Click **"Publish"** button at the top after all 5 are configured

**Note**: Set "Used for Tracking" to **"No"** for all 5 data types since build 1.0.0 (14) doesn't have tracking permission.

---

### Step 4: Select Price Tier
**Link**: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight

- [ ] Find "Pricing and Availability" section
- [ ] Click "Edit" or price field
- [ ] Select: **Free**
- [ ] Select: **All Countries** (default)
- [ ] Click "Save"

### Step 5: Complete Age Rating
**Link**: https://appstoreconnect.apple.com/apps/6756714869/distribution/ios/version/inflight

- [ ] Find "Ratings and Review" section
- [ ] Click "Edit" or "Manage Rating"
- [ ] Complete questionnaire - select **"None"** for all categories:
  - [ ] Cartoon or Fantasy Violence: **None**
  - [ ] Realistic Violence: **None**
  - [ ] Profanity or Crude Humor: **None**
  - [ ] Sexual Content or Nudity: **None**
  - [ ] Alcohol, Tobacco, or Drug Use: **None**
  - [ ] Mature/Suggestive Themes: **None**
  - [ ] Gambling and Contests: **None**
  - [ ] Horror/Fear Themes: **None**
  - [ ] Medical/Treatment Information: **None**
  - [ ] Unrestricted Web Access: **None** or **Infrequent**
- [ ] Review calculated rating (should be 4+)
- [ ] Click "Save"
