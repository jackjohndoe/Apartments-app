# Using Suhw201.svg as App Icon

## ✅ Found: `assets/Suhw201.svg`

This SVG file contains a building design that will work great as your app icon!

## 🚀 Quick Conversion Steps

### Method 1: Online Converter (Fastest - 2 minutes)

1. **Go to:** https://cloudconvert.com/svg-to-png
   - Or: https://convertio.co/svg-png/
   - Or: https://svgtopng.com/

2. **Upload:** `assets/Suhw201.svg`

3. **Settings:**
   - **Width:** 1024 pixels
   - **Height:** 1024 pixels
   - **Background:** White (#FFFFFF) or Gold (#FFD700) - choose what looks better
   - **Format:** PNG

4. **Convert and Download**

5. **Replace Icon:**
   - Rename downloaded file to `icon.png`
   - Copy to `assets/icon.png` (replace existing)

### Method 2: Using Inkscape (Free Desktop App)

1. **Download Inkscape:** https://inkscape.org/release/

2. **Open SVG:**
   - Open Inkscape
   - File → Open → Select `assets/Suhw201.svg`

3. **Export as PNG:**
   - File → Export PNG Image
   - Set width: 1024
   - Set height: 1024
   - Choose background color (white or gold)
   - Click "Export"
   - Save as `icon.png`

4. **Replace:**
   - Copy exported file to `assets/icon.png`

### Method 3: Using ImageMagick (Command Line)

If you have ImageMagick installed:

```bash
magick convert -background white -resize 1024x1024 assets/Suhw201.svg assets/icon.png
```
