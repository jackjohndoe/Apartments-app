## 📋 Detailed Steps

### Step 1: Open EAS Dashboard
1. Open your web browser
2. Go to: **https://expo.dev/accounts/michaelkaysea/projects/nigerian-apartments-app/builds**
3. Make sure you're logged in to your Expo account

### Step 2: Find "Create a build" Button
Look for one of these:
- A **"Create a build"** button (usually at the top right)
- A **"New build"** button
- A **"Start build"** button
- Or click on the **"Build"** link in the left sidebar, then look for a create button

### Step 3: Select Build Configuration
When the build form appears, select:

**Platform:**
- ✅ **iOS** (select this)

**Profile:**
- ✅ **production** (select this)

**Distribution:**
- ✅ **App Store** (for App Store submission)

### Step 4: Review Settings
Check that:
- Version: 1.0.0
- Build number: Will auto-increment (21+)
- Profile: production
- Platform: iOS

### Step 5: Start the Build
1. Click **"Create build"** or **"Start build"** button
2. The build will start automatically
3. You'll see a progress indicator

### Step 6: Monitor Progress
- Build takes approximately **15-30 minutes**
- You can watch progress on the same page
- You'll receive an email when complete
- Status will show: "In progress" → "Finished"

---

## ✅ What Happens After Build Completes

1. **Automatic Upload**: Build automatically uploads to App Store Connect
2. **TestFlight**: Appears in TestFlight within 10-30 minutes
3. **Ready for Submission**: Can then submit for App Store review
