Why KYC Matters

  • Regulatory requirement — CBN (Central Bank of Nigeria) guidelines mandate identity verification for financial services
  • Prevents fraud — stops money laundering, identity theft, and scam accounts
  • Builds trust — verified users feel safer transacting on the platform
  • Unlocks features — wallet withdrawals are blocked until KYC is completed

Bank Account Binding

How it works

  1. User provides: Bank name, Account number, Account holder name
  2. Backend verifies the account against Flutterwave (Nigerian bank API)
  3. Account is bound to the user's profile
  4. Only bound accounts can receive withdrawals
Why? Prevents funds from being sent to accounts the user doesn't own. Critical for AML compliance.

Security & Data Protection

Data Protection

  • 🔒 Document numbers are masked in the database
  • 🔒 Only the last 4 digits stored in plain text
  • 🔒 Full numbers are never logged or returned in API responses
  • 🔒 Bank verification done server-side via Flutterwave — no account numbers in frontend

Audit & Compliance

  • 📋 All admin actions are audit-logged
  • 📋 Each log includes: admin email, timestamp, action, and affected entity
  • 📋 KYC decisions (approve/reject) create compliance flag records
  • 📋 Wallet status changes generate audit entries with reason
